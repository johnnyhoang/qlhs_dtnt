Purpose

This page manages support payment batches. A batch groups payment amounts by month and year, then shows the detail lines for each student inside the selected batch.

Important areas

  • Batch list: the main table of payment periods already created.
  • Create batch dialog: used to register a new payment cycle before detail data is imported or reviewed.
  • Detail drawer: opens when you inspect a batch and shows each student payment line.
  • Class filter inside the drawer: narrows the detail list for a selected class.
  • Import / Export: used to move detail rows in and out of the system.

Recommended workflow

  1. Create the batch first with the correct month and year.
  2. Open the batch detail drawer and confirm the selected batch before importing.
  3. Import detail rows only into the intended batch.
  4. Filter by class when checking distribution or troubleshooting one cohort.
  5. Export the batch when finance or leadership needs an external file.
