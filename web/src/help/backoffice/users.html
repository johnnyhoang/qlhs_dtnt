Purpose

This page manages internal user accounts, roles, activation state, module permissions, and teacher class assignments. It is the main access-control screen for the backoffice.

Important areas

  • User table: lists name, email, role, classes, active status, and permission actions.
  • Role column: changes the user role directly from the table.
  • Permission modal: controls module-level view/edit permissions and stores extra user notes.
  • Teacher class assignment: appears when the selected user role is TEACHER.

Recommended workflow

  1. Search for the target user first.
  2. Review role and activation status before editing module permissions.
  3. Grant only the modules the user actually needs.
  4. For teachers, keep the assigned classes accurate because some module visibility may depend on class ownership.
