Purpose

This page manages CDS evaluation periods. An evaluation period defines the school year label and the allowed date range during which forms can be submitted.

Important areas

  • Period table: lists configured periods with start date, end date, and calculated status.
  • Create / Edit modal: defines the year label and the opening/closing date range.
  • Print report action: opens the aggregate print report for the selected period.

Administration guidance

  1. Create the period before users start filling CDS forms.
  2. Use clear year labels because they appear across the CDS module.
  3. Check the date range carefully. It controls whether the form is not yet open, open, or locked.
