Purpose

This workspace manages the public CMS. It is used to maintain content pages, define the public navigation tree, and control which pages are visible on the public site.

Tabs

  • Content pages: create or edit HTML/PDF pages, choose the slug, summary, content type, and publication state.
  • Menu structure: assign public menu labels, connect them to pages, and reorder the tree with drag and drop.

Publishing workflow

  1. Create or update the page first.
  2. Save draft while you are still editing.
  3. Publish only after the content and slug are correct.
  4. Create or update the menu entry so the page becomes discoverable on the public website.
  5. Use unpublish or delete carefully because menu links may depend on the page.
