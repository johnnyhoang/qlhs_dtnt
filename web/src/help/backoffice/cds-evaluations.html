Purpose

This page lists CDS evaluation forms. It is the operational entry point for creating a new evaluation, revisiting an existing draft, reviewing a submitted form, printing the form, or deleting owned forms when permitted.

Important areas

  • Evaluation table: shows the period, submitter, group scores, level, status, and update date.
  • Create new evaluation: opens the form for a new submission.
  • Edit / View action: opens the existing form. Drafts can still be edited; submitted forms are read-only.
  • Print action: opens the print-friendly report view.
  • Delete action: only available to the owner or an admin.

Working rules

  1. Use draft status while collecting evidence and checking scores.
  2. Submit only after all mandatory evidence links are complete.
  3. Use the print view for PDF printing or Word export after the form is ready.
