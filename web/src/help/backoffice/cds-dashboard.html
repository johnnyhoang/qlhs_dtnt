Purpose

This page summarizes the current digital transformation scoring status. It is intended for quick monitoring of how many evaluations have been submitted and what the current average scores look like.

Important areas

  • Total evaluations: how many CDS evaluations are currently stored.
  • Average teaching score: average performance for the teaching and learning group.
  • Average management score: average performance for the governance group.
  • Radar chart: visual comparison of the two main CDS groups.

How to use it

  1. Use this screen to see the overall CDS position before opening detailed evaluations.
  2. Compare the two score groups. A large gap may point to uneven implementation.
  3. Open the evaluation list if you need to inspect individual submissions.
