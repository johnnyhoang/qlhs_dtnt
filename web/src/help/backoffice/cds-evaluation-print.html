Purpose

This page is the print-friendly version of a single CDS evaluation. It prepares the content for PDF printing or Word export with a formal document header and structured scoring table.

Important actions

  • Download Word: exports the current report body as a Word-compatible document.
  • Print PDF / Printer: opens the normal browser print flow for PDF or physical printing.

Usage notes

  1. Review the header and submitter details before exporting.
  2. Use Word export when the document needs manual editing after download.
  3. Use browser print when you need a stable PDF snapshot of the current report.
