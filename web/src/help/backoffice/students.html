Purpose

This page is the main student master list. It is used to search, review, create, update, import, export, and maintain the core student profile data used by the other QLHS modules.

Important areas

  • Summary cards: show total students, currently enrolled students, and students who have left.
  • Search and class filters: narrow the list by student code, student name, or one or more classes.
  • Main table: shows the core columns such as student code, full name, class, birth date, gender, status, and audit fields.
  • Expanded row details: expose address, phone number, bank details, and audit details.
  • Import / Export: import CSV updates or export the current filtered list.

Typical workflow

  1. Filter the list first so you only work with the intended class or student group.
  2. Click an existing row to open the student editor, or use Add student to create a new record.
  3. Review status carefully. Other modules depend on whether a student is still active.
  4. Use CSV import for bulk onboarding or bulk corrections.
  5. Use export when you need a current operational list outside the system.
