Purpose

This page manages daily meal cut-off reporting. It is used to record whether a student should be excluded from breakfast, lunch, or dinner on a selected date.

Important controls

  • Date picker: changes the working day for meal status updates.
  • Search and class filter: find a student quickly before changing meal status.
  • Breakfast / Lunch / Dinner checkboxes: toggle the cut-off state for each meal.
  • Note field: capture the reason or operational note for the change.
  • Import / Export: support bulk CSV updates and reporting.

How to use it safely

  1. Confirm the selected date before making any change. The date directly affects which record is updated.
  2. Use the class filter when processing a single class to reduce mistakes.
  3. Tick only the meals that should be stopped for that student on that date.
  4. Add or update the note if the exception needs traceability.
  5. Use CSV import only when the source file matches the required format.
