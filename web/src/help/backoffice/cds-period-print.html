Purpose

This page prints the aggregate CDS report for one evaluation period. It is intended for leadership review, internal reporting, and formal PDF or Word output.

What is shown

  • Document header: school header, national header, and report title.
  • Submission count: how many official evaluation forms were received.
  • Average score table: average results by criterion group.
  • Conclusion block: the overall CDS level for the school.

Actions

  1. Use Download Word if the report needs to be edited after export.
  2. Use Print report / PDF for a final signed or archived version.
  3. Review the selected period before sharing the document externally.
