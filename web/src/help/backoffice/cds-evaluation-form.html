Purpose

This page is the detailed CDS self-evaluation form. It is used to score criteria, provide evidence links, save a draft, and submit the final evaluation for the selected period.

Important areas

  • Header section: identifies the submitter and the evaluation period.
  • Tabs: split the form into two groups, teaching/learning and governance.
  • Score field: available only for criteria that are score-based.
  • Evidence link field: mandatory for required criteria when submitting officially.
  • Draft and Submit buttons: save work-in-progress or lock the form as the official version.

Recommended workflow

  1. Check the evaluation period before entering scores.
  2. Work through each criterion and attach evidence links where relevant.
  3. Use Save Draft while the form is still incomplete.
  4. Use Official Submit only after validating mandatory evidence.
  5. After submission, reopen the record from the list for read-only review or printing.
