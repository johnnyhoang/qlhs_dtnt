Purpose

This page manages shared reference lists used by the rest of the application. These values usually drive drop-down choices, classifications, and validation rules in other modules.

Important areas

  • Category tabs: switch between the master-data groups configured in the system.
  • Search: filter the current category only.
  • Table / mobile list: review the code, display name, order, status, and notes for each item.
  • Add / Edit modal: create or maintain one dictionary entry.
  • Import / Export: bulk maintain one selected category.

Usage notes

  1. Always confirm the selected tab before importing or adding a new record.
  2. Keep ordering and activation status clean because downstream screens may rely on them.
  3. Use delete carefully when old student or finance records may still reference the item.
